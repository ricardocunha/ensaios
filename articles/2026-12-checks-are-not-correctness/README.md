# My agent checks passed. The answers were still wrong.

**Status:** draft · **Branch:** `article/2026-12-checks-are-not-correctness` · **Target date:** 2026-12-18

A series post tying together the four agent articles (compliance, disaster risk, road network, maintenance): every deterministic check on model output proved that something exists (a quote, a number, a station code, a justification), not that it was used correctly; and in every project, decisions made by code held up better than decisions made by the model. No code of its own: every number comes from the four articles' `code/docs/RESULTS.md`, which must be merged into `main` before this one (the links point there).
